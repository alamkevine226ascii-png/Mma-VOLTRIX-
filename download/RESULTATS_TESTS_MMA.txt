2. BACKTEST PUBLIC DU MODÈLE (GET /api/mma/predictions)
--------------------------------------------------------------------------------
Exécution réelle au 2026-11-08 :

  Combats analysés      : 46
  Favoris confirmés     : 33
  Taux de réussite      : 72 %
  Ventilation fiabilité : Bonne 26/38 · Moyenne 7/8 · Limitée 0/0
  Combats exclus        : 32 (données ESPN insuffisantes chez un combattant)
                          + 2 (statistiquement trop serrés pour départager)

Méthodologie : le modèle voltrix-mma-v1 est recalculé sur les combats
terminés en base et confronté aux vainqueurs réels. Le résultat est publié
tel quel dans l'application (onglet Paramètres), y compris s'il est
défavorable. Limites affichées avec le résultat :
  - biais de recul : les stats de carrière utilisées sont celles connues
    aujourd'hui, pas celles au moment du combat (taux indicatif) ;
  - échantillon limité aux combats dont les deux combattants disposent de
    données suffisantes ;
  - les combats trop serrés sont exclus du décompte.

4. INCIDENT RÉEL RENCONTRÉ ET CORRIGÉ
--------------------------------------------------------------------------------
  Symptôme : HTTP 403 intermittents du CDN ESPN (sports.core.api) lors du
  remplissage historique (backfill) des combattants des combats terminés.
  Cause : bridage du CDN après des rafales de requêtes (664 requêtes en
  448 s) ; indépendant de la chaîne User-Agent (vérifié par tests croisés).
  Corrections :
    - une relance polie (2,5 s) sur 403/429 dans le client HTTP du module
      core (src/modules/core/http.ts) ;
    - script de backfill incrémentiel avec comptage honnête des enrichis-
      sements partiels (scripts/backfill_finished_fighters.ts) ;
    - l'ordonnanceur applicatif (toutes les 6 h) complète les fiches
      restantes sans intervention.
  Résultat : 166 combattants ciblés, 127 fiches complètes au moment du
  test, le reste étant enrichi progressivement par l'ordonnanceur.
